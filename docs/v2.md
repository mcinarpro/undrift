# Undrift v2 – the cockpit of the Piste system

Written 2026-11-05. The method it serves is `SYSTEM.md` in the hub (`mcinarpro/core`); read it
first – this file only says what the window does. v2 is a rebuild of the pages on the same shell:
what Undrift was for (a Board of Issues per Project in Focus) is replaced, not extended.

## What is kept

- The Tauri v2 shell: the tray (closing hides), window state, single window, Linux and Windows.
- The Geist theme: `DESIGN.md`'s tokens, type, shape and motion, the shadcn components in
  `src/components/ui/`, `Action`, the Find command menu (`Ctrl K`), the topbar with pill tabs.
- From the bridge: `repo.rs` (git read-only per folder), `sessions.rs` and `transcripts.rs` (the open
  and last Sessions, local to the machine), `gh.rs` (pull requests and their checks), `terminal.rs`
  (a terminal running `claude` in a folder), `user.rs` (the NavUser).

## What goes

The Board, Lanes, Notes, the Shelf, Up Next as it was, Focus, Today, Let Go, the Starts, the Graph,
`reads_first.rs`, `history.rs`'s Drift strip. Focus and Today become `status: sprint` and the Round;
the Graph answers no question the method asks. `GLOSSARY.md` and `DESIGN.md` are rewritten to the
new words – Piste, Sprint, Reprise, Round – in the same change as the pages.

## Where it reads, where it writes

| Source | What is kept |
| --- | --- |
| `<hub>/pistes/*.md` | the frontmatter, the one-line purpose, the `## Reprise` section as text |
| `<hub>/0 Inbox/` | the count, and the titles for Review |
| `git` in each Piste's `folder` | last commit time, branch, changed and unpushed counts – as today |
| `gh pr list` per Piste with a `repo` | open pull requests and their checks, as today |
| `~/.claude/sessions`, `~/.claude/projects` | this machine's Sessions per folder, as today |

`hub` is a new key of `config.json`, default `~/workspace/core`.

**Writes – the contract changes, recorded in ADR 0005 with this spec.** Undrift writes to the hub,
and only there:

- a capture: one file in `0 Inbox/`, in the format of the hub's `/capture` skill, `source: undrift`;
- a Piste's `status` and `rhythm` – making one Piste the Sprint takes the flag from the other;
- `git add` of exactly those files, `commit`, `pull --rebase --autostash`, `push`, in the hub alone.

It still never writes to a Piste's repository, never fetches there, never writes to GitHub and calls
no model. The Reprise card is written by `/close` inside Claude Code, never by the window.

**Sync.** The hub is pulled at launch, every 15 minutes and before each write. A conflict shows a
banner naming the files and stops writing until it is resolved by hand – never resolved by Undrift.

## Four screens

1. **Today** – the opening screen, nothing else competes with it:
   - the Sprint: its title, its Reprise card, a flag when the card is stale (a commit newer than
     `reprise:`), its open Session if any. **Enter** resumes that Session, or opens `claude` in the
     folder – the global `agent/CLAUDE.md` makes it read the card first;
   - the Round: the one Piste most behind its rhythm, its card, and three actions – Open, Capture a
     note about it, Delegate (phase 3);
   - today's learning Pistes as small rings: touched today or not;
   - a capture field, `C` to focus it.
2. **Pistes** – every Piste as a row: type, status, rhythm, days since last touch, late, stale card,
   pull requests to review. Grouped Sprint, late, on rhythm, paused. Changing status and rhythm
   happens here.
3. **A page per Piste** – its purpose, the full card, git state, open pull requests with their checks
   (Fix the checks stays), this machine's Sessions, and Resume, New Session, Open the folder.
4. **Review** (phase 2) – the week, computed and never generated: touches per Piste against its
   rhythm, cards rewritten, captures in, the inbox titles, and the Sprint for next week. Its last
   action opens `claude` in the hub on `/weekly-review`.

**Global capture.** A shortcut, active even when the window is hidden, opens a one-line box over
everything; Enter writes the capture and commits it, Escape closes. Learning and dev ideas alike go
to the same inbox.

**Autostart.** Undrift opens at login, hidden in the tray, so the hub is already pulled when Today is
first shown.

## Bridge changes

- `hub.rs` – find the hub, parse `pistes/*.md` (`.ok()?` on anything malformed, as with `~/.claude`),
  write a capture, set a field, run the hub's git sync. Atomic writes, temp file then rename.
- `config.rs` – drop Focus, Today, Let Go, Starts; add `hub`.
- New commands: `pistes_now`, `capture`, `set_piste`, `sync_hub`; `resume`, `new_session`,
  `fix_checks` stay.
- Plugins Mehmet installs himself: `bun tauri add global-shortcut`, `bun tauri add autostart`.

## Phases

1. **Phase 1, one week** – Today, Pistes, the Piste page, global capture, hub sync, autostart.
2. **Phase 2** – Review, learning rings.
3. **Phase 3, perhaps never** – Delegate: cut an Issue and hand it to an agent from the Round;
   spaced-repetition quizzes for languages from the learning notes.

Two weeks of use between phases; the measure is in `SYSTEM.md`. A phase nobody uses stops the next.
