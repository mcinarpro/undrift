# Undrift v2 – the desktop cockpit

Written 2026-11-05, updated the same day with the decisions of the design conversation. The method
it serves is `SYSTEM.md` in the hub (`mcinarpro/core`). Mockups: Today, Projects, a Project, Life,
Review and the capture box, in Geist, light and dark.

**Scope: the desktop app only**, on Linux and Windows, the same build on every machine. No phone
app and no web page for now – the phone is used only through Claude Code's Remote Control, which
is not Undrift's concern.

## Words

| Word | Means |
| --- | --- |
| **Project** | Anything that moves forward: `dev`, `learning` or `maintenance`. One file per Project in the hub, with a rhythm. |
| **Sprint** | The one Project worked deep for **5 days**. Chosen at the Review, or changed on purpose with a reason. |
| **Reprise** | The card at the bottom of a Project's file – Done, Next, Blocked by – rewritten by `/close`, checked against git. |
| **Round** | **13:30, 25 minutes**: the one Project most behind its rhythm, moved one step or delegated. |
| **Life** | Family, admin, the house: a board of post-its with dates, kept in the hub. |
| **Post-it** | One piece of paper on a board: a GitHub Issue on a Project's board, a Life item on the Life board. |

## What is kept from v1

- The Tauri v2 shell: the tray (closing hides), window state, single window, no native decorations.
- The Geist theme: `DESIGN.md`'s tokens, type, shape and motion, the shadcn components, `Action`,
  Find (`Ctrl K`), the topbar with pill tabs – and **the paper**: pad colours, the torn band, the
  grain, the lean, the dotted board ground.
- From the bridge: `repo.rs`, `sessions.rs`, `transcripts.rs`, `gh.rs`, `terminal.rs`, `user.rs`.

Gone: Lanes, the Shelf, Focus, Today-as-a-selection, Let Go, the Starts, the Graph, `reads_first.rs`,
the Drift strip. `GLOSSARY.md` and `DESIGN.md` are rewritten to the words above with the pages.

## Five screens

1. **Today** – the opening screen.
   - The Sprint strip: the Project, *day 3 / 5*, the Reprise's Next, **Resume** on Enter, and where
     to open it – *Terminal* or *Claude Desktop*.
   - The Sprint's board in post-its: Ready, Doing, Review, Done. In Doing, an open Session is a white
     card pinned above its post-it, with the question it waits on.
   - On the right: Life this week (post-its), the Round, Learning (rings, *Done today*).
   - At the bottom: the capture field.
2. **Projects** – every Project as a row, grouped Sprint, behind their rhythm, on rhythm, paused:
   rhythm, the last 7 days, last touch, state (late, stale card, pull request), Next.
3. **A Project** – its board in post-its, its Reprise card, git, this machine's Sessions; status,
   rhythm, *Make it the Sprint*, *Open in*.
4. **Life** – four columns, *Someday Soon*, *This Week*, *Waiting On*, *Done*; a colour per category,
   *Kids* pink, *Admin* yellow, *House* green, *Health* lavender; a post-it may point to a note
   (*→ Hollogne school*). On the right: *Coming Up* by date, and *Just Captured* from the inbox.
5. **Review** – Sunday, computed and never generated: days on the Sprint, tickets done, captures,
   Life done, the rhythm held per Project, the inbox, the next Sprint.

**Capture** – `C` in the window, or `Ctrl Alt Space` from anywhere, even with the window hidden: one
line, an optional *Life / Project / Note* chip, Enter. It lands in `0 Inbox/` and is committed.

## Where the post-its come from

- **A Project's board**: the GitHub Project's *Status* field when the repository has one (Home Sweet
  Plan does: Ready, In progress, In review, Done). Otherwise derived: Ready = open Issues, Doing =
  the Issue of the current branch or open Session, Review = an open pull request, Done = closed in
  the last 7 days. Read-only through `gh`; a post-it is moved on GitHub, or by the repo's own skills.
- **Life**: one file per item in `<hub>/life/`, frontmatter `title`, `category`, `column`, `due`,
  `note`. Undrift creates and moves them – drag, or the post-it's `⋯` menu.

## Reads and writes

| Reads | |
| --- | --- |
| `<hub>/projects/*.md`, `<hub>/life/*.md`, `<hub>/0 Inbox/` | the Projects, Life, the inbox |
| `git` per Project folder, read-only | as v1 |
| `gh` – Issues, pull requests and checks, Project boards | read-only, as v1 |
| `~/.claude/sessions`, `~/.claude/projects` | this machine's Sessions, as v1 |

**Writes – in the hub only (ADR 0005):** a capture; a Life post-it created or moved; a Project's
`status` and `rhythm`; a learning Project's *Done today* (its date added to `done:` in the
frontmatter, the last 60 kept). Each is `git add` of those files, `commit`, `pull --rebase
--autostash`, `push`. The hub is pulled at launch, every 15 minutes and before each write; a
conflict shows a banner and stops writes until it is resolved by hand.

Never a write to a Project's repository or to GitHub.

## Claude

- Undrift starts **the unmodified `claude` binary**, signed in with Mehmet's own plan, in a terminal
  or in Claude Desktop. It never reads, stores or forwards a Claude credential.
- `claude -p` only on an explicit click – *Propose the inbox sort*, *Draft the card* – never on a
  timer or in a loop: the plan's limits assume ordinary, individual use (Anthropic's legal and
  compliance page, read 2026-11-05).
- A setting for an API key as a fallback, should the plan's terms change again.

## Build

- Plugins Mehmet installs: `bun tauri add global-shortcut`, `bun tauri add autostart`.
- Bridge: `hub.rs` (find the hub, parse Projects and Life, write, sync), `boards.rs` (a Project's
  post-its from `gh`), `config.rs` (drop v1's keys, add `hub` and `openIn`).
- Phase 1, one week: Today, Projects, a Project, capture, hub sync, autostart.
- Phase 2: Life, Review, learning rings.
- Phase 3, perhaps: Delegate from the Round, quizzes from the learning notes.
- Two weeks of use between phases; a phase nobody uses stops the next.
